# TGL port — прогресс

Точный порт The Guardian Legend (NES) методом «механического перевода»:
игра работает на встроенном эмуляторе процессора, процедуры по одной
заменяются переведённым кодом на C. Каждое изменение проверяется
сверкой памяти с записью из Mesen кадр за кадром.

## Устройство

- `core/cpu6502.*` — процессор NES (все официальные инструкции, частые неофициальные)
- `core/nes.*` — память, маппер UNROM, PPU по строкам, геймпад, система перехвата процедур (hooks)
- `tests/cpu_smoke.c` — короткие проверки процессора
- `tests/replay.c` — сверка с записью `tgl_logger2.lua` (с перезагрузки игры)
- `tools/tgl_logger2.lua` — скрипт записи для Mesen 2
- ROM и записи в репозиторий не кладутся (`.gitignore`)

Сборка и проверки: `make`, затем `make test ROM=... LOG=...`
