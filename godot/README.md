# TGL Port — оболочка Godot

Godot-проект, который показывает игру из ядра порта (`native/tglcore.dll`).

## Запуск

1. Нужны Godot 4.x **.NET** (Mono) и .NET SDK 8 или новее (`dotnet --list-sdks`).
2. В Godot: **Import** → выбрать `project.godot` в этой папке → **Import & Edit**.
3. Нажать **F5** (Run). При первом запуске Godot соберёт C#-проект.
4. ROM ищется по пути `C:/TGL_claude/rom/Guardian Legend, The (USA).nes`;
   если его там нет, появится окно выбора файла, путь запомнится.

## Управление

| NES | Клавиатура | Геймпад |
|---|---|---|
| Крестовина | Стрелки / WASD | Крестовина, левый стик |
| B (огонь) | Z | нижняя кнопка |
| A (доп. оружие) | X | правая кнопка |
| Start | Enter | Start |
| Select | Shift | Back / Select |
| Перезагрузка | F5 | — |
| Выход | Esc | — |

`native/tglcore.dll` собирается из `core/` командой `make dll` (clang + lld-link), ROM в проект не входит.

## Моды

Godot при запуске применяет все файлы `mods/*.tglpatch` (папка `mods` рядом с `project.godot`):
правки ложатся на копию ROM в памяти, файл ROM не меняется. F7 — перечитать моды и начать заново.
Патч собирается из понятного описания (`.tglmod`) инструментом `tools/mod.py`, пример —
`mods/example.tglmod` в репозитории. Правки данных (здоровье, урон, волны) работают вместе с
переводом; если правка задевает код, патч выключает перевод и игра идёт на эмуляторе.

## Сохранения

F2 — сохранить, F4 — загрузить, F3 — сменить ячейку (1-3). Файлы — в папке пользователя Godot
(`user://save_N.tglstate`). Сохранение привязано к сборке ядра и к ROM с модами: после обновления
`tglcore.dll` или смены модов старые сохранения не загрузятся (будет сообщение). Пароли игры работают всегда.

## Читы

F9 — бессмертие (жизнь в конце каждого кадра возвращается к максимуму). K — враги гибнут с первого
попадания снаряда игрока (столкновение телом — как обычно). Не F8: в Godot F8 останавливает запущенную игру.
O — все спецоружия уровня 3 (выбор — на экране паузы, Select в лабиринте; после выключения
полученное оружие остаётся). Заголовок окна показывает,
что оно включено.
